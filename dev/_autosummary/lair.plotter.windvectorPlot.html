lair.plotter.windvectorPlot#

lair.plotter.windvectorPlot(data, wd='WD', ws='WS', ax=None, unit_length=False, **kwargs)[source]#

Plot wind vectors.

Parameters:

  • data (pd.DataFrame) – Data to plot.

  • wd (str, optional) – Wind direction variable. Defaults to ‘WD’.

  • ws (str, optional) – Wind speed variable. Defaults to ‘WS’.

  • ax (plt.Axes | None, optional) – Axis to plot on. Defaults to None.

  • unit_length (bool, optional) – Normalize vectors to unit length. Defaults to False.

  • **kwargs – Additional arguments to pass to plt.quiver.

Returns:

plt.Axes – Axis with the plot

Return type:

Axes
